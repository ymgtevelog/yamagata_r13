# 山形ドライブ R13（Yamagata Drive R13）

国道13号を米沢から金山まで、沿線13市町村をめぐる3Dドライブゲームです。
無料・広告なし・アプリ内購入なし。Android アプリのほか、iPhone・Android のブラウザでも遊べます。

- ブラウザで遊ぶ：https://ymgtevelog.github.io/yamagata_r13/play/
- Android の APK：https://ymgtevelog.github.io/yamagata_r13/ の「Android アプリ」からダウンロード
- アプリの紹介：https://ymgtevelog.github.io/yamagata_r13/
- プライバシーポリシー：https://ymgtevelog.github.io/yamagata_r13/privacy.html
- BGM：[山形たびめぐり音楽帳](https://www.youtube.com/playlist?list=PLCg-62_Qkruc)（制作・発信：[山形イベログ](https://www.youtube.com/@ymgt_evelog)）
- パッケージ名：`jp.ymgtevelog.drive13`

不具合の報告やお問い合わせは、Discord サーバー「[山形ドライブ R13](https://discord.gg/DbBp5qREY)」または ymgt.evelog@gmail.com へお願いします。

Google Play 公開に向けたベータテスターを[募集しています](https://forms.gle/B7wKQ6jXHzxBBDWKA)。

本アプリは個人が制作した非公式のゲームで、山形県・各市町村・国・道の駅などの公式アプリではありません。

## このリポジトリについて

| パス | 内容 |
|---|---|
| `docs/` | GitHub Pages で公開するページ（アプリの紹介・プライバシーポリシー） |
| `docs/play/` | ブラウザ版のゲーム本体（Android アプリ版と同じ内容を、ブラウザで動くようにしたもの） |
| `docs/download/` | 紹介ページから配布する Android 版の APK（最新版のみ置く） |
| `docs/v/` | 結果カードの「記録の確認用」QR コードの内容を確かめるページ |

署名鍵（`*.jks` など）やパスワードは、このリポジトリに置かないでください（`.gitignore` で除外しています）。
